                                                                                                                                                                                                                                                                          Rahul, અત્યાર સુધી તારા Terraform AWS projectમાં આ મુખ્ય errors આવ્યા છે:
#	Error	Solution
1	Duplicate required providers configuration	main.tf માં એક જ terraform block રાખવો.
2	Unexpected backend block	backend "s3" ને terraform blockની અંદર મૂકવો.
3	S3 bucket does not exist (NoSuchBucket)	S3 bucket પહેલાં create કરવો, પછી terraform init -migrate-state ચલાવવું.
4	DependencyViolation: Security Group cannot be deleted	પહેલાં તપાસવું કે કયા EC2 instances એ Security Group વાપરે છે.
5	DependencyViolation: Subnet cannot be deleted	Subnet સાથે જોડાયેલા ENI/EC2/VPC Endpointની dependency તપાસવી.
6	GuardDuty VPC Endpointને કારણે subnet delete ન થવો	Endpoint vpce-04c7fa3fe27ccb390 તપાસવો; જરૂરી હોય તો તેને જાળવી રાખવો અને subnet deletion ટાળવી.
7	Duplicate private subnet resources	voting_subnet_private અને voting_subnet_private_rahul વચ્ચે યોગ્ય subnet પસંદ કરી references સુધારવા.
